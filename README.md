# nioi

A minimal writing site published with GitHub Pages and Jekyll.

## Publishing

Articles live in `_posts/` as Markdown files named `YYYY-MM-DD-slug.md`.

Each post starts with front matter:

```yaml
---
layout: post
title: "文章標題"
date: 2026-08-09
---
```

The site is designed to be edited directly through GitHub. Once GitHub Pages is enabled for `main` / root, pushes to `main` are published automatically.
